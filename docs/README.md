## How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Preview the live application
npm start
# Opens on http://localhost:5183

# 3. Launch the VitePress documentation portal
npm run docs:dev
# Opens on http://localhost:5184

# 4. Build the documentation for production
npm run docs:build
```
